# prodexsys-icons


Иконки, используемые в проектах и ПО Prodexsys и Syfora.


## /icons-ms
SVG-иконки для использования в MasterSCADA 4D.

## /icons
SVG-иконки веб-сервиса.

## /webDynamic/CommonIconPack
"Динамические" SVG-иконки веб-сервиса. Белый цвет заменён на <u>currentColor</u> для возможности переопределения цвета при помощи CSS-аттрибута <u>'color'</u> в контексте HTML. Номенклатурно состав идентичен **/icons**.
